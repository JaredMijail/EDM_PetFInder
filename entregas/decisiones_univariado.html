Transformación de VideoAmt y total_faces en variables binarias a partir de los diagnósticos del análisis univariado.

AUTORES

Jared Mijail Ramírez Escalante · María Paula Silva Capera

El Análisis Univariado Diagnóstico mostró que VideoAmt y total_faces tienen \(RIQ = 0\): sus cercas de Tukey colapsan en el valor nulo y la escala de razón original es poco informativa. Aquí se fija la recodificación resultante.

Recodificación

Ver código 
datos_dec <- datos |>
  dplyr::mutate(
    # VideoAmt → binaria: presencia/ausencia de video
    VideoAmt_bin = factor(
      ifelse(VideoAmt == 0, "Sin video (0)", "Con video (≥ 1)"),
      levels = c("Sin video (0)", "Con video (≥ 1)")
    ),
    # total_faces → binaria: presencia/ausencia de rostros (los perdidos se conservan)
    total_faces_bin = factor(
      dplyr::case_when(
        is.na(total_faces) ~ NA_character_,
        total_faces == 0   ~ "Sin rostros (0)",
        total_faces >= 1   ~ "Con rostros (≥ 1)"
      ),
      levels = c("Sin rostros (0)", "Con rostros (≥ 1)")
    )
  )

# Tabla de frecuencias de una variable ya recodificada (respeta el orden de los niveles)
tabla_decision <- function(x, etiqueta = "Nivel") {
  f <- if (is.factor(x)) x else factor(x)
  f <- droplevels(f[!is.na(f)])                        # conserva el orden de los niveles
  tb <- tibble::tibble(Nivel = levels(f), n = as.integer(table(f))) |>
    dplyr::mutate(`Frecuencia relativa` = 100 * n / sum(n),
                  `Frecuencia acumulada` = cumsum(`Frecuencia relativa`),
                  n = ent(n),
                  `Frecuencia relativa` = pct(`Frecuencia relativa`),
                  `Frecuencia acumulada` = pct(`Frecuencia acumulada`))
  if (anyNA(x)) {
    tb <- dplyr::bind_rows(tb, tibble::tibble(Nivel = "Valores perdidos", n = ent(sum(is.na(x))),
                                              `Frecuencia relativa` = "—", `Frecuencia acumulada` = "—"))
  }
  knitr::kable(tb, col.names = c(etiqueta, "Frecuencia absoluta", "Frecuencia relativa",
                                 "Frecuencia acumulada"), align = c("l", "r", "r", "r"))
}

VideoAmt → binaria

Corte: 0 · ≥ 1.

\(RIQ = 0\) con ambos límites en 0 y 96,2 % sin video; los conteos solo llegan a 8 y el 99,6 % está en 0 o 1. La única señal con masa es presencia/ausencia.

  • 0 → Sin video (0)
  • ≥ 1 → Con video (≥ 1)

Verificación

Ver código 
stopifnot(
  !anyNA(datos_dec$VideoAmt_bin),                                    # VideoAmt no tiene perdidos
  sum(is.na(datos_dec$total_faces_bin)) == sum(is.na(datos_dec$total_faces)),  # sólo los 341 estructurales
  identical(levels(datos_dec$VideoAmt_bin), c("Sin video (0)", "Con video (≥ 1)")),
  identical(levels(datos_dec$total_faces_bin), c("Sin rostros (0)", "Con rostros (≥ 1)"))
)
cat(sprintf("Verificación superada: %s filas recodificadas; únicos perdidos = %s (total_faces, sin foto).\n",
            ent(nrow(datos_dec)), ent(sum(is.na(datos_dec$total_faces_bin)))))
Verificación superada: 14.993 filas recodificadas; únicos perdidos = 341 (total_faces, sin foto).
