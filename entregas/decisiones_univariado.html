Transformación de Quantity y Fee (ordinales) y de VideoAmt y total_faces (binarias) a partir de los diagnósticos del análisis univariado.

AUTORES

Jared Mijail Ramírez Escalante · María Paula Silva Capera

El Análisis Univariado Diagnóstico mostró que Quantity, Fee, VideoAmt y total_faces tienen \(RIQ = 0\): sus cercas de Tukey colapsan y la escala de razón original es poco informativa. Aquí se fijan los cortes y la recodificación resultante.

Recodificación

Ver código 
datos_dec <- datos |>
  dplyr::mutate(
    # Quantity → ordinal de 3 niveles (orden creciente en el número de animales)
    Quantity_ord = factor(
      dplyr::case_when(
        Quantity == 1     ~ "Único (1)",
        Quantity %in% 2:3 ~ "Pocos (2–3)",
        Quantity >= 4     ~ "Muchos (≥ 4)"
      ),
      levels  = c("Único (1)", "Pocos (2–3)", "Muchos (≥ 4)"),
      ordered = TRUE
    ),
    # Fee → ordinal de 3 niveles: gratuita vs. tarifa baja/alta (masa equilibrada)
    Fee_cat = factor(
      dplyr::case_when(
        Fee == 0    ~ "Gratuita (0)",
        Fee < 100   ~ "Tarifa baja (< 100)",
        Fee >= 100  ~ "Tarifa alta (≥ 100)"
      ),
      levels  = c("Gratuita (0)", "Tarifa baja (< 100)", "Tarifa alta (≥ 100)"),
      ordered = TRUE
    ),
    # VideoAmt → binaria: presencia/ausencia de video
    VideoAmt_bin = factor(
      ifelse(VideoAmt == 0, "Sin video (0)", "Con video (≥ 1)"),
      levels = c("Sin video (0)", "Con video (≥ 1)")
    ),
    # total_faces → binaria: presencia/ausencia de rostros (los perdidos se conservan)
    total_faces_bin = factor(
      dplyr::case_when(
        is.na(total_faces) ~ NA_character_,
        total_faces == 0   ~ "Sin rostros (0)",
        total_faces >= 1   ~ "Con rostros (≥ 1)"
      ),
      levels = c("Sin rostros (0)", "Con rostros (≥ 1)")
    )
  )

# Tabla de frecuencias de una variable ya recodificada (respeta el orden de los niveles)
tabla_decision <- function(x, etiqueta = "Nivel") {
  f <- if (is.factor(x)) x else factor(x)
  f <- droplevels(f[!is.na(f)])                        # conserva el orden de los niveles
  tb <- tibble::tibble(Nivel = levels(f), n = as.integer(table(f))) |>
    dplyr::mutate(`Frecuencia relativa` = 100 * n / sum(n),
                  `Frecuencia acumulada` = cumsum(`Frecuencia relativa`),
                  n = ent(n),
                  `Frecuencia relativa` = pct(`Frecuencia relativa`),
                  `Frecuencia acumulada` = pct(`Frecuencia acumulada`))
  if (anyNA(x)) {
    tb <- dplyr::bind_rows(tb, tibble::tibble(Nivel = "Valores perdidos", n = ent(sum(is.na(x))),
                                              `Frecuencia relativa` = "—", `Frecuencia acumulada` = "—"))
  }
  knitr::kable(tb, col.names = c(etiqueta, "Frecuencia absoluta", "Frecuencia relativa",
                                 "Frecuencia acumulada"), align = c("l", "r", "r", "r"))
}

Quantity → cualitativa ordinal

Corte: 1 · 2–3 · ≥ 4.

\(RIQ = 0\) porque \(Q1 = Q3 = 1\) (77,1 % ofrece un solo animal) y las cercas colapsan en [1, 1]. El corte agrupa por orden del conteo y conserva masa en cada nivel: el menos frecuente retiene el 8,5 % (1.280 casos), así que ninguno queda degenerado.

  • 1 → Único (1)
  • 2–3 → Pocos (2–3)
  • ≥ 4 → Muchos (≥ 4)
Ver código 
tabla_decision(datos_dec$Quantity_ord, "Nivel de cantidad")

Fee → cualitativa ordinal (3 niveles)

Corte: 0 · 1–99 · ≥ 100.

\(RIQ = 0\) con el 84,5 % en 0 (Fee = 0, adopciones gratuitas). Para dar resolución al 15,5 % que cobra se parte en dos usando el umbral cercano a la mediana de las tarifas positivas (100 MYR), buscando repartir su masa lo más equitativamente posible: quedan 1.062 y 1.268 anuncios (45,6 % y 54,4 % de los que cobran). Un 50/50 exacto no es alcanzable porque el valor 100 agrupa 408 anuncios.

  • 0 → Gratuita (0)
  • 1–99 → Tarifa baja (< 100)
  • ≥ 100 → Tarifa alta (≥ 100)

Verificación

Ver código 
stopifnot(
  !anyNA(datos_dec$Quantity_ord),                                   # Quantity no tiene perdidos
  !anyNA(datos_dec$Fee_cat),                                        # Fee no tiene perdidos
  !anyNA(datos_dec$VideoAmt_bin),                                   # VideoAmt no tiene perdidos
  sum(is.na(datos_dec$total_faces_bin)) == sum(is.na(datos_dec$total_faces)),  # sólo los 341 estructurales
  identical(levels(datos_dec$Quantity_ord), c("Único (1)", "Pocos (2–3)", "Muchos (≥ 4)")),
  identical(levels(datos_dec$Fee_cat), c("Gratuita (0)", "Tarifa baja (< 100)", "Tarifa alta (≥ 100)"))
)
cat(sprintf("Verificación superada: %s filas recodificadas; únicos perdidos = %s (total_faces, sin foto).\n",
            ent(nrow(datos_dec)), ent(sum(is.na(datos_dec$total_faces_bin)))))
Verificación superada: 14.993 filas recodificadas; únicos perdidos = 341 (total_faces, sin foto).

Las cuatro variables recodificadas —Quantity_ord, Fee_cat, VideoAmt_bin y total_faces_bin— quedan en datos_dec para los análisis posteriores, sin pérdida de observaciones.

## `Quantity` → cualitativa ordinal

**Corte: 1 · 2–3 · ≥ 4.**

$RIQ = 0$ porque $Q1 = Q3 = 1$ (77,1 % ofrece un solo animal) y las cercas colapsan en `[1, 1]`. El corte agrupa por orden del conteo y conserva masa en cada nivel: el menos frecuente retiene el 8,5 % (1.280 casos), así que ninguno queda degenerado.

- 1 → **Único (1)**
- 2–3 → **Pocos (2–3)**
- ≥ 4 → **Muchos (≥ 4)**

```{r}
#| label: dec-Quantity
#| tbl-cap: "Distribución de Quantity recodificada (ordinal)"
tabla_decision(datos_dec$Quantity_ord, "Nivel de cantidad")
```

## `Fee` → cualitativa ordinal (3 niveles)

**Corte: 0 · 1–99 · ≥ 100.**

- 0 → **Gratuita (0)**
- 1–99 → **Tarifa baja (< 100)**
- ≥ 100 → **Tarifa alta (≥ 100)**

## Verificación

```{r}
#| label: dec-verificacion
#| echo: true
stopifnot(
  !anyNA(datos_dec$Quantity_ord),                                   # Quantity no tiene perdidos
  !anyNA(datos_dec$Fee_cat),                                        # Fee no tiene perdidos
  !anyNA(datos_dec$VideoAmt_bin),                                   # VideoAmt no tiene perdidos

```
